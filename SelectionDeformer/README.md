# 選択範囲デフォーマー（Cinema 4D 2027 / 試作版）

ポリゴン・ポイント・エッジを選んだ状態から、Cinema 4D 標準のデフォーマー
（屈曲・シアー・テーパー・ツイスト・膨張・ベベル）を、**選択範囲に合わせた大きさと向き**で1クリックでセットします。
調整したら、そのまま「デフォーマー＋選択範囲タグ」として残すことも、**フリーズ**で変形を確定することもできます。

## 読み込み方

`SelectionDeformer` フォルダを、C4D 2027 のプラグインフォルダに置くか、ジャンクション（リンク）を張って、C4D を再起動します。

```
%APPDATA%\Maxon\Maxon Cinema 4D 2027_C7F976AA\plugins\SelectionDeformer
  → D:\05_Claude\C4D-Modeling-Plugins\SelectionDeformer（ジャンクション）
```

メニューは **機能拡張 ＞ SelectionDeformer** に入ります（「選択範囲デフォーマーパネル」「選択範囲に屈曲」…「選択範囲にベベル」「選択範囲デフォーマーをフリーズ」など10個）。
まず「選択範囲デフォーマーパネル」を開き、レイアウトにドッキングしておくと便利です。各コマンドはコマンドマネージャーからパレットやショートカットにも割り当てられます。
パネルを浮かせて使う場合も、Windows ではメインウィンドウをクリックしたときに裏へ隠れないようにしてあります（パネルの窓の所有者をメインウィンドウにしています。ほかのアプリより前には出ません）。

## 使い方

1. 編集可能なポリゴンオブジェクトで、ポリゴン・ポイント・エッジのどれかを選択します。
2. パネルの「種類」ボタン（屈曲・シアー・テーパー・ツイスト・膨張）を押します。
   - 選択範囲に合わせてデフォーマーが置かれ、選択した部分だけが変形します。
   - 向きがすぐ分かるように、少しだけ効かせた状態で作ります（屈曲・ツイスト 45°、テーパー・膨張 30%、シアーは先端が長さの約 20% ずれる強度）。
   - 箱はどの種類も選択範囲にぴったり合わせます（平らな面の厚み方向だけは、最小で最大辺の 5%）。
3. 強さはパネルの数値欄（屈曲・ツイストは角度、シアー・テーパー・膨張・ベベルは長さ）か、属性マネージャー・ビューのハンドルで調整します。向きが違うときは「起点をクリック」か「起点と方向」のボタンで直します。
4. 確定するときは「フリーズ」を押します。そのまま残せば、普通のデフォーマーとして使い続けられます。

あとから効かせる範囲を変えたいときは、メッシュで選択し直し、オブジェクトマネージャーでデフォーマーをクリックして「選択を取り直す」を押します（メッシュの選択はデフォーマーを選んでも残っています）。

デフォーマーを選んだまま「種類」ボタンを押すと、**箱と向きはそのままで種類だけ切り替わります**。
**Shift＋クリック**なら切り替えではなく、同じ選択範囲・同じ向きで新しいデフォーマーを**すぐ後ろに重ねて追加**します（例: テーパー＋ツイスト）。
パネルがアクティブ（浮いたパネルが前面、またはマウスがパネルの上）な状態で Shift を押している間は、各アイコンの右下に緑の＋が出ます。
選択範囲タグは重ねたデフォーマー同士で共有し、フリーズすると全部の変形が焼き込まれてからタグが消えます。

## ベベル

ベベルは、ほかの5種と仕組みが違います（角を削って面を増やすので、トポロジーが変わります）。

- **箱もフィールドもありません**。ベベルデフォーマーの「選択範囲」欄に、選択範囲タグの名前を入れて限定します（C4D 標準のやり方）。
  エッジから作るとエッジ選択タグ、ポリゴンからならポリゴン選択タグ、ポイントからならポイント選択タグを作り、コンポーネントモードもそれに合わせます。
- 「角度を使う」はオフにして作ります（オンだと、選んだエッジでも角度が浅いとベベルされないため）。オフセットは選択範囲の大きさの 3% です。
- 「起点と方向」のボタン（起点をクリック〜再フィット）はベベルでは使えません。量の欄は「ベベル: オフセット」を長さで表示・入力します（オフセットモードが「比例」のときは対象外）。
- **フリーズは、同じ設定のベベルツールをメッシュに直接かけます**。オブジェクトを作り直さないので、UV・選択範囲タグ・Nゴンも正しく更新されます（点・エッジ・ポリゴンの3モードとも、デフォーマーと同じ形になることを確認済み）。
- ほかの種類との切り替え・重ねもできます。ベベル（エッジ）からほかの種類にするときは、そのエッジの点からポイント選択タグを作って使います（使われなくなったエッジのタグは消します）。
- 選択範囲タグの名前で探すので、同じ名前のタグを持たない子オブジェクトにはベベルはかかりません。
- 選択範囲タグの名前を変えたときは、ベベルの「選択範囲」欄の名前も合わせてください（C4D 標準の仕様）。

## パネルのボタン

| ボタン | 動き |
|---|---|
| 屈曲〜ベベル（アイコン） | メッシュ選択中は新規作成。選択範囲デフォーマー選択中は種類の切り替え。Shift＋クリックで同じ選択範囲に重ねて追加（Shift 中はアイコンに緑の＋） |
| 1段目の数値欄（量） | 選んでいる種類で中身が切り替わる「数値欄＋スライダー」。**屈曲＝強度（曲げる角度）、ツイスト＝角度（ひねる角度）** は角度のまま（スライダー ±360°）。**シアー＝先端のずれ、テーパー＝先端の片側の絞り、膨張＝中央の片側のふくらみ、ベベル＝オフセット** は強度（%）を実際に動く長さで表示・入力し、強度を逆算して入れる（単位は C4D の単位設定に従う）。長さのスライダーの範囲はシアー＝±主軸の長さの半分、テーパー・膨張＝±片側の幅 |
| 2段目の数値欄（角度） | **屈曲・シアーの角度（曲げる向き・ずらす向き）**。スライダーは属性マネージャーと同じ 0〜360°。シアーは向きを変えても先端のずれ（長さ）が変わらないよう強度を換算し直す（属性マネージャーで角度を変えると、強度はそのままでずれ量が変わる）。テーパー・ツイスト・膨張・ベベルでは使えない |
| （数値欄の共通） | 範囲外の値は数値欄に入力できる。属性マネージャーやハンドルで変えると表示も追従。ドラッグ中もビューがリアルタイムに変わり（属性マネージャーのスライダーと同じ）、アンドゥはドラッグ全体で1回 |

パネルの幅が種類ボタンの列より広がらないよう名前は短くし、詳しい説明はアイコンのツールチップに出します）:

| ボタン | 動き |
|---|---|

| 選択を取り直す | 親メッシュの今の選択（今のモード）で、デフォーマーの選択範囲タグを取り直し、新しい選択で向きと起点を自動判定し直して箱を合わせ直す（手で変えた向きは自動に戻るので、必要なら取り直した後に「起点と方向」のボタンで直す）。3ds Max で下のモディファイヤの選択を変えたときに近い使い方。選択の種類が同じならタグの中身を書き換え（同じタグを共有して重ねたデフォーマーも合わせ直す）、種類が変わればタグを付け替えて古いタグを消す。フィールドに自分で足したレイヤーは残る。アンドゥ1回 |

| デフォーマ後に編集（アクティブなビュー） | ビューの表示オプション「デフォーマ後に編集」（BASEDRAW_DATA_DEFORMEDEDIT）と同じ設定を、アクティブなビューに対して切り替える。プラグインが勝手に値を変えることはなく、ビューのメニューで切り替えたときやビューを切り替えたときは表示が追従する |

「起点」モードのクリックでは、クリックしたメッシュの位置（変形前の場所に戻して判定）が箱の中心から一番離れている方向の面が起点になります。
付け根の近くなら底面、先端の近くなら上面、平らな面の長辺の中ほどならその辺の側面です。

## 向きと起点の自動判定

- **起点は非選択側**: 選択範囲と未選択部分の境目（付け根）を起点にします。
  主軸は「境目の中心 → 境目からいちばん遠い部分」の向きです（突起なら付け根→先端、端だけがつながった面なら、つながった端→反対の端）。
  オブジェクトの軸や選択範囲の形の軸と 15° 以内なら、その軸にぴったり揃えます。
- **曲げ方向**: 面の選択なら面の法線の側（面が反り返る向き）、突起などは断面の薄い方向。
- **エッジの流れに合わせる**: 面の中の向きや、主軸まわりの回転（H 角度）は、選んだポリゴンのエッジが並ぶ方向に揃えます。
  斜めの面や、正方形に近い選択でも、箱がエッジに沿って選択範囲ぴったりになります（主軸はエッジ方向のうち長い方。ほぼ同じ長さならオブジェクトの軸に近い方）。
  円柱の輪のようにエッジの向きがばらばらなときは、点の分布から決めます。
- **境目が選択範囲をぐるりと囲んでいて方向が決まらないとき**（面の真ん中だけを選んだ、筒の中ほどの帯を選んだ等）は、形から主軸を決めます。
  平らな面は面内の一番長い方向、突起・筒は伸びる方向です。起点は、境目が偏っている端、それも無ければオブジェクトの中心に近い端です。

## 仕組み（プラグインが無い PC でも開けます）

- 作られるのは標準のデフォーマーと選択範囲タグだけです。プラグインが入っていない PC やレンダーファームでも、シーンはそのまま正しく開いて同じ形になります。
- 影響範囲は、デフォーマーの **フィールド** に入れた「変数タグ」レイヤーで、選択範囲タグ（`SD_Sel`、`SD_Sel.1`…）に絞っています。
  選択範囲タグを手でフィールドにドラッグしたのと同じ形なので、ぼかしなどのフィールドを上に重ねて調整できます。
- 昔の「制限」タグは使いません（旧版の試作で作ったデフォーマーは読み取れます。種類を切り替えるとフィールド方式に移ります）。
- 箱の底面（ローカル -Y）が効果 0、上面が最大です（膨張は両端 0）。この底面を選択範囲の起点に合わせています。
- フリーズは、対象のデフォーマーだけを効かせた結果を元のオブジェクトに書き戻します。オブジェクトを作り直さないので、タグ・マテリアル・UV・階層はそのまま残ります。アンドゥ1回で戻せます。
- フリーズの対象は、選択中の選択範囲デフォーマー、または選択中のオブジェクトの直下にある選択範囲デフォーマーすべてです。普通のデフォーマーは焼き込みません。

## 注意点（試作版）

- **メッシュに子オブジェクトがあると、子も一緒に変形します。** フィールドの変数タグレイヤーは、そのタグを持たないオブジェクトには重み1を返すためです（C4D 標準の挙動）。
  このときは C4D のステータスバー（画面左下）とコンソールに「⚠子オブジェクトも一緒に変形します」と出ます（パネルにはメッセージ欄を置いていません）。フリーズで焼き込むのはメッシュだけなので、フリーズすると子は元の形に戻ります。
- 選択範囲の両端が未選択部分とつながっていると、先端側の境目で段差やひずみが出ます（標準デフォーマーの仕様）。
- **シアーの強度は、C4D の仕様で「箱の幅に対する %」です**。
  先端のずれ＝強度 ×（cos角度×X 幅/2, 0, sin角度×Z 幅/2）で、湾曲・フィレットは途中の曲がり方だけを変えます（C4D 2027 で実測）。
  平らな面を法線方向にずらすと X 幅（厚み）が小さいので、強度は数百 % になります。実際の量はパネルの量の欄で mm で見られ、mm で入力もできます。
  「起点と方向」のボタンや再フィットで箱の幅が変わったとき、パネルでシアーの角度（ずらす向き）を変えたときは、実際のずれ量が変わらないよう強度を換算し直します。
  屈曲から切り替えたシアーは屈曲の向き（角度）を引き継ぎ、その向きで先端が長さの約 20% ずれる強度で作ります。
- **テーパー・膨張の強度は「軸からの距離に対する %」です**（箱の大きさには関係しません）。
  テーパーは先端の点が、膨張は中央の点が「強度×軸からの距離」だけ内側／外側に動きます。湾曲・フィレットは途中の形だけを変えます（C4D 2027 で実測）。
  パネルの量の欄は、選択範囲のいちばん外側（箱の X・Z の広い方の側面）の点が片側で何 mm 動くかです。箱を手で広げた場合は、箱の側面の位置での量になります。
- ベベルのフリーズは、ほかのデフォーマーより前に（元の形に）ベベルをかけます。ベベルの前に屈曲などを重ねていた場合は、フリーズ後の形が重ねた状態と少し変わることがあります。ベベルの「角度を使う」を手でオンにした場合も、フリーズは選んだ要素すべてにベベルをかけます。
- 種類を切り替えると、デフォーマー自体のキーフレームは引き継ぎません。
- 法線タグ（Phong 以外の明示的な法線）を持つメッシュは、フリーズ後に法線が古いままになります。
- プラグイン ID はテスト用（1000001〜1000010）です。テスト用が10個しかないので、ベベルのコマンドは印のキーと同じ 1000010 を使っています。配布する前に正式な ID に差し替えてください（`seldeform/core.py` の先頭）。

## ファイル

```
SelectionDeformer/
  SelectionDeformer.pyp   … 登録
  seldeform/core.py       … 選択範囲の解析、作成・向き・再フィット・フリーズ
  seldeform/ui.py         … パネル、起点クリックツール、コマンド
  seldeform/winowner.py   … Windows でパネルがメインウィンドウの裏に隠れないようにする
  seldeform/icons.py      … 種類ボタンのアイコン（Shift 中の緑の＋付き）
  res/                    … 起点クリックツールの登録に必要な最小限のリソース
../tests/
  run_selection_deformer_tests.py … 通しテスト（突起・平らな面・エッジ選択・円柱の側面・平らな面のシアー・斜めの正方形・選択の取り直し・重ねて追加・ベベル・パネルの数値欄・起点クリックの当たり判定、122件）
  sd_test_scene.c4d               … 確認用のテストシーン
```

通しテストは、C4D のスクリプトマネージャーで `tests/run_selection_deformer_tests.py` を開いて実行します。
新しいドキュメントを作って確かめるので、作業中のシーンには触りません。結果はコンソールに出ます。
